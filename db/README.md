# db

`schema.sql`: modelo físico de la base de datos (tablas `Partida`, `Jugada`,
`Jugador`, `ConfiguracionDeDificultad`), entregado por Modelado y Gestión de
Datos.

`seeds/`: datos de ejemplo para pruebas locales y para el entorno compartido
de integración (ver `docs/documento-GC.md`).

Responsable: Modelado y Gestión de Datos.
